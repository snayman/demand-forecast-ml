## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install pandas numpy scikit-learn matplotlib streamlit joblib statsmodels xgboost
```

### 2. Генерация данных
```bash
python generate_data.py
```

### 3. Обучение моделей и EDA
```bash
python train_model.py
```

### 4. Запуск веб-приложения
```bash
python -m streamlit run app.py
```

Приложение откроется по адресу: **http://localhost:8501**

## 📊 Результаты моделей

| Модель | MAE | RMSE | MAPE |
|---|---|---|---|
| Линейная регрессия | 609.6 | 1274.7 | 8.9% |
| SARIMA (1,1,1)(1,1,0,12) | 98.7 | 156.6 | 2.2% |
| Random Forest | 393.7 | 523.2 | 8.9% |
| XGBoost | 241.7 | 304.5 | 5.5% |
| **Gradient Boosting** | **241.3** | **333.1** | **5.1%** |

> 🏆 Активная модель в приложении: **Gradient Boosting**  
> ✅ Целевой показатель паспорта: MAPE < 15% — **выполнен** (5.1%)

## 🔧 Признаки модели

| Признак | Описание |
|---|---|
| `product_enc` | Закодированный ID товара |
| `month`, `quarter`, `year` | Временные компоненты |
| `t` | Порядковый номер месяца |
| `weekend_ratio` | Доля выходных дней в месяце (признак дня недели) |
| `days_in_month` | Количество дней в месяце |
| `lag_1`, `lag_2`, `lag_3` | Продажи за 1, 2, 3 предыдущих месяца |
| `roll_mean_3`, `roll_mean_6` | Скользящее среднее за 3 и 6 месяцев |
